DeutschWort — German vocabulary PWA
=====================================

What is included
----------------
- Exactly 2,500 vocabulary entries (968 nouns, 813 verbs, 362 adjectives, plus adverbs and core function words).
- Russian and English translations.
- Nouns include their article and plural form.
- Four typed-answer practice modes.
- Frequency-ordered learning path, daily streak, accuracy and local progress.
- Basic spaced repetition (review intervals increase after correct answers).
- Searchable word library with per-entry DWDS reference links.
- Offline-capable PWA; install from Chrome on Android.

Install on Android
------------------
1. Upload/deploy this folder to a static HTTPS host (for example GitHub Pages).
2. Open the deployed URL in Chrome on your Samsung phone.
3. Open Chrome menu (⋮) and choose "Install app" or "Add to Home screen".
4. Launch DeutschWort from the home screen. Progress is stored locally in that browser.

Important data-quality note
---------------------------
This is a carefully filtered 2,500-word learning list, not a fully human-proofread
commercial dictionary. Frequency ordering is derived from the multi-source
Grundwortschatz dataset. English translations come from that dataset; Russian
translations are matched from the FreeDict German-Russian dictionary. Noun
articles/plurals are retained from Grundwortschatz, and entries with detected
conflicts against FreeDict's explicit gender marker were excluded. Some entries
have no explicit FreeDict gender tag. Examples and enrichment may include
automatically generated material in the source dataset. Please use the linked
DWDS references to check nuanced senses.

Visuals
-------
Each card uses a simple emoji mnemonic / category illustration rather than a
bespoke picture for every individual word.
